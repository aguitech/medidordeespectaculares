Pipeline

De la captura a la decisión

Cuatro pasos automatizados. Cada uno auditable. Cada uno con trazabilidad criptográfica.

01

Personal Data

Validación estructural de CURP contra RENAPO, RFC, edad y reglas de negocio.

API: POST /applicants
02

Documents

INE, CURP, comprobante — extracción OCR + hash SHA256 + verificación cruzada.

API: POST /documents/upload
03

Biometric

Selfie + liveness detection + match contra el rostro del INE. Encoding 128-d.

API: POST /biometric/verify
04

Risk & Decision

17 features, modelo rule-fusión con explainability, decisión o escalado a revisión.

API: POST /risk/evaluate
Capacidades

Tres capas, un solo pipeline

Cada vertical opera independiente pero se sincroniza en el flujo de originación.

⚡

KYC Digital

Validación de identidad con CURP/RFC, comprobante de domicilio, OCR de documentos INE y validaciones automáticas contra listas de sanciones.

👤

Biometría Facial

Liveness detection pasiva + match contra documento. Encoding vectorial 128-d. Compatible con FaceTec / Onfido / iProov en producción.

📊

ML Risk Scoring

17 features demográficos, financieros y de comportamiento. Modelo rule-fusión explicable con bandas de riesgo AAA-D y razones por escrito.

🛡️

Audit Trail Completo

Cada paso se persiste con actor, timestamp, IP y hash. Cumplimiento CNBV, LFPDPPP y trazabilidad de extremo a extremo.

⚙️

Reglas de Negocio

Hard rules configurables: ratios de monto/ingreso, geo-restricciones, listas negras, criterios de escalado a revisión humana.

🔁

Human-in-the-Loop

Cuando el score cae en zona gris, escalado automático a un revisor con vista del audit log. Override con justificación firmada.

Seguridad & Compliance

Diseñado para producción financiera

Cada decisión es defendible. Cada API request tiene un request_id, un hash de payload, y queda registrada en el audit log para compliance y reproducción forense.

🔐
JWT + bcrypt

Auth con tokens HS256 firmados, passwords encriptadas con bcrypt cost=12, rotación de secrets.

🗄️
PostgreSQL + SQLAlchemy 2.0

Transacciones ACID, indices optimizados, pool de conexiones. Backups con dump WAL-ready.

📜
Audit Log inmutable

Cada cambio de estado registra actor, timestamp, IP y payload. Tabla append-only con índices de búsqueda.

🚦
Rate limiting + CORS

Headers de seguridad, validación de payloads Pydantic v2, OpenAPI schema público en /api/docs.
